# Meme Organizer

Android-приложение для локального хранения, организации и поиска мемов.
Поддерживаются изображения, GIF и видео. Основная библиотека работает без
аккаунта и без сервера: файлы копируются во внутреннее хранилище приложения.

> Проект находится на ранней стадии разработки. Перед обновлением приложения
> рекомендуется создать резервную копию библиотеки.

## Возможности

- Импорт одного или нескольких изображений, GIF и видео из галереи и файлового
  менеджера.
- Добавление файлов через системное меню Android «Поделиться».
- Предпросмотр до импорта, проверка дубликатов по SHA-256 и локальное хранение
  копий файлов.
- Полноэкранный просмотр, масштабирование изображений и GIF, управление видео.
- Описания и ручные теги, избранное, счётчик использования и сортировка.
- Пользовательские альбомы, а также системные альбомы «Недавно добавленные» и
  «Недавно использованные».
- Копирование изображений и GIF, отправка всех поддерживаемых типов медиа в
  другие приложения.
- Сохранение локальной копии отдельного мема в выбранное пользователем место.
- Локальный гибридный поиск по описаниям и тегам: семантический поиск + BM25.
- Экспорт диагностических журналов и ручная переиндексация библиотеки.
- Ручные и автоматические резервные копии библиотеки.

## Быстрый старт

1. Установите сборку приложения или соберите её самостоятельно.
2. На вкладке «Главная» нажмите `+` и выберите файлы.
3. При необходимости добавьте описание и теги в предварительном просмотре либо
   позже — из полноэкранного просмотра мема.
4. Используйте поиск в AppBar после установки текстовой модели.

### Текстовая модель для поиска

Библиотека, импорт и ручная организация не требуют модели. Текстовый поиск по
описаниям и тегам становится доступен после установки пакета модели:

1. Откройте «Настройки» → «Текстовая модель».
2. Нажмите «Проверить обновления модели» либо выберите заранее скачанный архив.
3. После установки при необходимости запустите «Переиндексировать библиотеку» в
   разделе «Для разработчиков».

Пакет модели, его манифест и Smoke Test Pack разрабатываются и публикуются
отдельно: [alexo375/meme-organizer](https://github.com/alexo375/meme-organizer).
Приложение проверяет целостность архива и совместимость версии перед установкой.

## Резервные копии

В «Настройках» доступны два режима:

- **Ручной архив** — сохраняет ZIP с медиа, описаниями, тегами, пользовательскими
  альбомами, избранным и статистикой использования. Восстановление заменяет
  текущую библиотеку только после проверки содержимого архива.
- **Автоматическое копирование** — создаёт один актуальный архив в выбранной
  пользователем папке раз в 3 дня, неделю или 2 недели. Там же можно запустить
  создание копии вручную и посмотреть последнюю ошибку.

Модели, ML-индексы, настройки приложения и диагностические журналы не входят в
резервную копию. После восстановления библиотеки нужно переиндексировать её,
чтобы снова использовать семантический поиск. Формат архива описан в
[docs/library_backup_format_v1.md](docs/library_backup_format_v1.md).

## Приватность и данные

- Медиафайлы и библиотека по умолчанию хранятся только на устройстве, во
  внутреннем хранилище приложения.
- Удаление мема из библиотеки не удаляет исходный файл пользователя.
- Удаление приложения удаляет его внутреннее хранилище; используйте экспорт или
  резервное копирование для сохранения библиотеки.
- Сетевая связь нужна только для необязательной проверки и скачивания обновлений
  текстовой модели.
- Диагностические журналы хранятся локально и экспортируются исключительно по
  явному действию пользователя.

## Сборка из исходников

Требования: Android Studio, JDK 17 и Android SDK с `compileSdk 36`.

```bash
git clone https://github.com/Landilf/MemeOrganaizer.git
cd MemeOrganaizer
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`. Для запуска тестов:

```bash
./gradlew testDebugUnitTest
./gradlew connectedDebugAndroidTest
```

## CI

GitHub Actions запускает unit-тесты и собирает debug APK для push в `dev` и
`main`, а также для pull request в `main`. Успешная сборка APK прикладывается к
запуску workflow как артефакт.

Push тега `v*` запускает отдельный workflow signed release APK. Настройка
keystore и GitHub Secrets описана в [docs/releasing.md](docs/releasing.md).
