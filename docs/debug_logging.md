# Отладочные логи

В debug-сборке используются два тега Logcat:

- `MemeOrg/ML` — установка пакета, открытие модели, токенизация, инференс, индексация и поиск;
- `MemeOrg/App` — обычные события приложения.

Для просмотра только модельных событий в Logcat используй фильтр `tag:MemeOrg/ML`. В ML-лог не записываются исходные тексты запросов, описания и теги: вместо них указываются длина текста, количество объектов, ID мема и время выполнения. Это позволяет диагностировать производительность, не раскрывая содержимое библиотеки.

Это диагностический Logcat-канал. Light-логи для обучения, ручной экспорт JSONL и пользовательская настройка согласия будут реализованы отдельно по контракту v0.2.

## Ручной экспорт

В debug-сборке в настройках доступен раздел «Для разработчиков». Кнопка «Выгрузить логи» предлагает выбрать место сохранения и создаёт `meme-organizer-events.jsonl.gz` с техническими событиями.

Опция «Включить копии мемов» формирует `meme-organizer-full-debug.zip`: `events.jsonl`, `memes.jsonl` с ID и хешами, а также копии медиа из локальной библиотеки. Она включена по умолчанию; пользователь может выключить её перед экспортом, поскольку архив может быть большим и содержит личные файлы.
