# Формат ручной резервной копии v1

Архив имеет имя по умолчанию `meme-organizer-library-backup.zip` и формат ZIP.
Его корневой файл `manifest.json` — обычный JSON (не JSON Lines); медиа находятся
по путям `media/<sha256>`.

```json
{
  "format": "meme-organizer-library-backup",
  "version": 1,
  "created_at_ms": 0,
  "memes": [],
  "albums": []
}
```

Каждый мем содержит хеш и исходное имя файла, тип и MIME-тип, дату добавления,
описание, теги, флаг избранного, дату и счётчик использования. Альбомы ссылаются
на мемы через `content_hash`, поэтому внутренние идентификаторы Room при
восстановлении не переносятся.

Перед заменой текущей библиотеки приложение проверяет версию формата, ссылки
альбомов, уникальность тегов и SHA-256 всех файлов из архива. Поисковые
эмбеддинги, установленные модели, отладочные журналы и настройки приложения не
включаются: эмбеддинги являются производными данными и пересоздаются отдельной
переиндексацией.
