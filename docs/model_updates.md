# Обновление текстовой модели

При запуске приложение при доступной сети запрашивает последний стабильный GitHub Release из `alexo375/meme-organizer`. Для сравнения используется только тег `v<major>.<minor>.<patch>-mobile`; название релиза остаётся произвольным текстом для пользователя.

Релиз обязан содержать:

- один архив модели с расширением `.tar.gz`;
- `SHA256SUMS.txt` с SHA-256 этого архива.

Если тег новее установленного, пользователь видит диалог. При отказе этот конкретный тег больше не предлагается автоматически, но остаётся доступен через кнопку «Проверить обновления модели» в настройках. При согласии приложение показывает ход скачивания, проверяет SHA-256 архива, распаковывает пакет и затем проверяет SHA-256 ONNX-модели из манифеста. Предыдущая активная модель сохраняется, пока все эти проверки не пройдут.

Пакет обязан содержать поле `release_tag` с тем же значением, что и GitHub-тег, например `"release_tag": "v0.2.0-mobile"`. При ручной и автоматической установке приложение сохраняет этот тег в локальных настройках и использует его как версию текущей модели. Пакет без `release_tag` не проходит проверку и не устанавливается.
