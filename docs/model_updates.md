# Установка и обновление пакета моделей

При запуске приложение при доступной сети запрашивает последний стабильный GitHub Release из `alexo375/meme-organizer`. Для сравнения используется только тег `v<major>.<minor>.<patch>-mobile`; название релиза остаётся произвольным текстом для пользователя. Предрелизы не участвуют в автоматической проверке, но доступны для явного выбора в разделе «Для разработчиков».

Релиз обязан содержать:

- один архив модели с расширением `.tar.gz`;
- `SHA256SUMS.txt` с SHA-256 этого архива.

Если тег новее установленного, пользователь видит диалог. При отказе этот конкретный тег больше не предлагается автоматически, но остаётся доступен через кнопку «Проверить обновления модели» в настройках. Раздел «Для разработчиков» выводит совместимые стабильные пакеты и предрелизы из GitHub Releases, чтобы выбранную версию можно было установить вручную. При согласии приложение показывает ход скачивания, проверяет SHA-256 архива, распаковывает пакет и затем проверяет SHA-256 файлов, объявленных в манифесте. Предыдущий активный пакет сохраняется, пока все эти проверки не пройдут.

Пакет обязан содержать поле `release_tag` с тем же значением, что и GitHub-тег, например `"release_tag": "v0.3.5-mobile"`. При ручной и автоматической установке приложение сохраняет этот тег в локальных настройках и использует его как версию текущей модели. Пакет без `release_tag` не проходит проверку и не устанавливается.

Установщик сохраняет совместимость с текстовыми пакетами v0.2 и принимает мультимодальный пакет v0.3: текстовый энкодер, OCR-detector, OCR-recognizer, ASR и fusion. В v0.3 проверяются SHA-256 всех объявленных файлов, а также заявленные в манифесте имена компонентов, рантаймы и спецификации входов и выходов. OCR подключён к обработке изображений и GIF. Для ASR пакета v0.3.7 поддерживается зафиксированный рантайм `sherpa-onnx:1.10.37`: приложение извлекает первую аудиодорожку видео через `MediaExtractor`/`MediaCodec`, приводит её к mono PCM 16 kHz и передаёт в ASR неперекрывающимися окнами по 25 секунд. Расшифровка сохраняется как ASR-чанки с временными отметками. Fusion-модель используется только для запуска Smoke Test Pack из раздела для разработчиков и не влияет на порядок поисковой выдачи.

Допустимый размер одного файла — до 300 МиБ, распакованного пакета — до 512 МиБ. Перед распаковкой каждого файла приложение оставляет не менее 64 МиБ свободного места и сообщает об его нехватке, не затрагивая уже установленный пакет.
